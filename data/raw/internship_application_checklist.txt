Internship Application Checklist

Before applying:
- Updated one-page CV
- Tailored cover letter
- GitHub and LinkedIn links working
- Project demos ready
- Transcript or grade sheet if required
- Professional email address

When applying:
- Read the job description carefully
- Match skills and keywords honestly
- Submit all required documents
- Use correct file names
- Track applications in a spreadsheet

After applying:
- Save the job post
- Note the application date
- Prepare for assessments
- Follow up politely if needed
- Reflect after each interview

Minimum tracking columns:
Company, Role, Date Applied, Status, Next Step
